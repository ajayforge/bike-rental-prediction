# Bike Rental Prediction (PRCP-1018)

Machine learning regression project to predict daily bike rental counts.

## Dataset
- day.csv — daily bike rental data

## Approach
- Data preprocessing and exploratory data analysis
- Compared regression models: Linear Regression, Ridge, Decision Tree, Random Forest, Gradient Boosting

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Jupyter Notebook

## Files
- Main notebook — bike rental regression pipeline
- `day.csv` — dataset file
