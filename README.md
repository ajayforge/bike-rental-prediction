# Bike Rental Prediction (PRCP-1018)

Machine learning regression project to predict daily bike rental counts using weather and seasonal data.

## Project Overview

Built an end-to-end regression pipeline covering data preprocessing, exploratory data analysis, feature preparation, model comparison, and performance evaluation.

## Dataset

- `day.csv` — daily bike rental data
- Target: daily bike rental count

The dataset contains weather and seasonal information that can be used to understand patterns in bike rental demand.

## Workflow

1. Data preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature preparation
4. Regression model training
5. Model comparison
6. Performance evaluation

## Models Compared

- Linear Regression
- Ridge Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor

## Results

The regression models were compared to identify the best-performing approach for predicting daily bike rental demand.

## Key Takeaways

- Explored the relationship between weather, seasonal factors, and bike rental demand.
- Compared linear and tree-based regression approaches.
- Applied a consistent preprocessing and model evaluation workflow.

Python · Pandas · NumPy · Scikit-learn · Jupyter Notebook
